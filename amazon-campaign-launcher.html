💡 Tips
• One row = one ad group. Same Campaign Name across rows = one campaign, multiple ad groups.

• Ad Products — separate SKUs (or ASINs for AMS) with semicolons: SKU001;SKU002

• Keywords / Targets — format is term,bid;term2,bid2. Omit bid to use Ad Group Default Bid.

• Auto campaigns — leave Keywords / Targets blank. Auto-targeting expressions are added automatically.

• ASIN campaigns — put ASINs in the Keywords / Targets column: B01XXX,30;B02XXX
